## Cross-cutting findings

1. **DUPLICATED COMPONENT:** Multiple routes deliberately reuse `ProfileComponent`, `PartnerOverviewComponent`, `ManagementDashboardComponent`, and `ManagementInventoryComponent`; route-data behavior needs tests before refactor.
2. **API GAP candidate:** Several list services return raw arrays (`users`, `rooms`, `reservations`, `invoices`). Server pagination/search must be verified in Java before any backend change.
3. **UX ISSUE:** `DataTable` has console-only Excel/PDF methods. They are not acceptance evidence and must remain hidden/removed until real export contract exists.
4. **TYPE ISSUE:** `any` is common at service boundaries. Replace incrementally with source-confirmed DTOs; do not invent fields.
5. **SECURITY AUDIT:** Some admin partner/property routes lack explicit `permissionGuard`. This is frontend UX risk only; backend remains mandatory security boundary.
6. **RESPONSIVE/A11Y:** Global tokens lack full spacing/radius/shadow/focus/motion definitions. Feature-02A addresses baseline; Feature-02H validates all pages.
