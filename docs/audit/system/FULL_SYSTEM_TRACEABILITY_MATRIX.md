# Full-System Traceability Matrix

Audit date: 2026-08-01

## Traceability Rules

- Every source capability ID appears exactly once in the matrix.
- `None`, `Missing`, source-only evidence and broken contracts are preserved as gaps; the matrix does not infer nonexistent links.
- `END_TO_END_VERIFIED` requires fresh executable evidence and maps only from `COMPLETE_VERIFIED`.
- `PARTIAL_CHAIN`, `PLACEHOLDER_LINK`, `BROKEN_LINK` and `MISSING_LINK` feed one concrete dependency-ordered T149 remediation task per row.
- `EXTERNAL_GATE` feeds sandbox adapter, contract, configuration and secret-management work without production credentials or real-money execution.
- Backend permission/ownership remains authoritative; frontend guards and hidden controls are presentation evidence only.
