## Required Lifecycle Order

The remediation dependency order for T149 must start with:

1. Remove entity/credential exposure in PROP-SUB-013 and repair the HTTP harness in PROP-SUB-025.
2. Establish one property approval state machine and pending-owner model for PROP-SUB-003,
   PROP-SUB-005, PROP-SUB-006 and PROP-SUB-008.
3. Make platform entitlement the single management source for PROP-SUB-020 and PROP-SUB-021.
4. Repair registration and claim lifecycle behavior, then add suspension/transfer/history.
5. Add expiry/revoke/plan administration only after authoritative state ownership is stable.

No production merchant, real payment, automatic downgrade/proration or refund-entitlement policy
may be enabled by these remediation tasks without the separate approvals already required by
Feature 007.
