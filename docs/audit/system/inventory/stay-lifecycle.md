## Evidence Rules

- `COMPLETE_VERIFIED` requires fresh executable evidence for the complete reachable behavior.
- Source inspection or a browser journey with intercepted APIs is not promoted to complete.
- Severity is `P0` for tenant, inventory or financial-integrity risk, `P1` for
  release-significant behavior, and `P2` for product quality.
- Operational reservation state and financial state remain separate; checkout totals,
  payment success and refunds must be derived from authoritative server records.
