## Evidence Rules

- `COMPLETE_VERIFIED` requires fresh executable evidence for the complete narrowly defined behavior.
- Source inspection and browser journeys with intercepted APIs are not promoted to complete.
- Severity is `P0` for tenant, permission or financial-integrity risk, `P1` for
  release-significant behavior, and `P2` for product quality.
- External mail/social-channel rows stay `BLOCKED_EXTERNAL` until a test provider or
  sandbox is configured; no production credential or real message is authorized.
