# Authentication And Account Inventory

Audit date: 2026-08-01
Scope: public registration and login, session lifecycle, password recovery/change,
profile/avatar, social login, registration email, authorization context and the
supporting persistence/test evidence required by FR-043 and FR-044.

## Evidence Rules

- `COMPLETE_VERIFIED` is used only when a fresh executed test proves the reachable behavior.
- Source inspection without a successful execution remains `PARTIAL`, `BROKEN`, `MISSING`,
  `PLACEHOLDER` or `BLOCKED_EXTERNAL`.
- Severity is `P0` critical access-control risk, `P1` release-significant, `P2` product-quality,
  and `P3` minor polish.
- The auth endpoints are public by design through `/api/auth/**`; account/profile/upload endpoints
  require an authenticated JWT. No production OAuth, SMTP or other real credentials were used.
