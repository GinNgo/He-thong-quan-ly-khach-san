# Full-System Audit Evidence

Capability statuses are evidence-based:

- `COMPLETE_VERIFIED`: fresh execution proves the reachable behavior.
- `PARTIAL`, `PLACEHOLDER`, `BROKEN`, `MISSING`: each requires an actionable task.
- `BLOCKED_EXTERNAL`: external dependency is unavailable, but simulator/adapter/contract/configuration guidance is present.
- `NOT_APPLICABLE`: only with a written product reason and no reachable route/API/spec requirement.
