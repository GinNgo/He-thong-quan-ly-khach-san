## 4. Dependency chain và nguyên nhân gốc

```text
ReservationLifecycleLockingTest
  -> @InjectMocks ReservationService
  -> assignRooms() / updateReservationStatus()
  -> ReservationService.mapToDTO()
  -> PropertyRefundRequestRepository.findByReservationIdOrderByRequestedAtAsc()
  -> repository field null vì fixture thiếu @Mock
```

`PropertyRefundRequestRepository` là dependency trực tiếp, `final`, của `ReservationService`. Nó được dùng trong DTO mapping để kết hợp canonical property-refund requests với legacy refund summaries. Repository không phải đối tượng chính của locking test; các test chỉ cần trạng thái “không có canonical refund” để hoàn tất mapping sau khi kiểm tra lock ordering.

Constructor dependency đã được thêm vào production service nhưng `ReservationLifecycleLockingTest` chưa cập nhật fixture. Mockito `@InjectMocks` không có mock cùng type nên truyền/để dependency null. Đây là fixture cũ, không phải lỗi locking, cancellation hoặc refund production behavior.
