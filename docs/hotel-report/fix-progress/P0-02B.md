## 4. Phân tích nguyên nhân gốc

`OperationalMetrics` là custom metrics wrapper trên Micrometer `MeterRegistry`. Nó không phải dependency trực tiếp của `SubscriptionController`; `CorrelationIdFilter` sử dụng nó để ghi timer/counter và metadata cho HTTP request.

Production context đúng: application runtime ở P0-02A đã khởi động, liveness/OpenAPI/Swagger/public API đều PASS và filter ghi log request bình thường. Trong production, component scanning và Micrometer auto-configuration cung cấp dependency cần thiết.

Fixture test đã cũ: `@WebMvcTest` chỉ nạp MVC slice, nhưng test import security/filter infrastructure kéo `CorrelationIdFilter` vào context mà không cung cấp `OperationalMetrics`. Các WebMvc test tương tự trong dự án đã dùng `@MockBean OperationalMetrics`.
