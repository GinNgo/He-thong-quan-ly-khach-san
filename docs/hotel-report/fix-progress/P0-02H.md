## Root cause và quyết định sửa

Production behavior đúng. `SecurityConfig` dùng request matcher cho public/authenticated contract, nhưng architecture test chỉ đọc annotation và allowlist cũ. Các endpoint mới dưới `/api/public/**`, public token confirmation và authenticated read-only `/my-hotels` chưa được khai báo trong rule.

Thay đổi tối thiểu:

- Bổ sung chính xác sáu public method vào `KNOWN_PUBLIC_ENDPOINTS`.
- Bổ sung riêng `HotelController.getMyHotels` vào allowlist hẹp `KNOWN_AUTHENTICATED_ENDPOINTS`.
- Giữ negative coverage: mọi endpoint khác không có annotation vẫn FAIL; không whitelist controller/package/path rộng.
- Không thêm annotation giả, không tạo bypass và không sửa production code/configuration.

File source sửa: `backend/src/test/java/com/hotel/security/EndpointSecurityArchitectureTest.java`.
