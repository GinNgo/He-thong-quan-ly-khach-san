## Root cause và configuration discovery

Bốn candidate Spring tìm thấy trong package `com.hotel.integration`:

1. `FinancialRefundConcurrencyIntegrationTest$TestApplication`
2. `FinancialRefundSecurityIntegrationTest$TestApplication`
3. `FinancialTenantFilterIntegrationTest$TestApplication`
4. `SupportConversationIsolationIntegrationTest$TestApplication`

Tất cả là nested static test-only `@SpringBootConfiguration` trong `backend/src/test/java/com/hotel/integration`, output tại `backend/target/test-classes`; không class nào đến từ production, generated source hoặc dependency khác.

Application entry đúng là `com.hotel.BackendApplication` tại `backend/src/main/java/com/hotel/BackendApplication.java`. Hai suite ở `com.hotel.integration` dùng `@SpringBootTest` không chỉ định `classes`, nên Spring quét package gần nhất, gặp cả bốn candidate và dừng trước khi đi lên package `com.hotel`.

Hai suite có cùng root cause, cùng candidate và cùng giải pháp tối thiểu. Production context đúng: package PASS và runtime baseline đã start thành công. Không sửa production bootstrap hoặc đổi annotation của bốn fixture cô lập.
